# Green Mind | العقل الأخضر

منصة عربية متعددة الصفحات للتحديات الثقافية والتقنية والبيئية والعلمية والفنية والقراءة والمجتمع، مع تصويت على المشاريع ولوحة نتائج مستقلة. جميع الملفات مباشرة في المجلد.

## صفحات الموقع

- `index.html`: الرئيسية
- `challenges.html`: التحديات وتصنيفاتها
- `voting.html`: تصويت الطلاب على المشاريع المعتمدة
- `results.html`: ترتيب المشاريع وعدد الأصوات والنقاط
- `admin.html`: صفحة الإدارة الخاصة وغير المرتبطة بقائمة الموقع العامة

## Firebase

إعدادات مشروع Firebase موجودة في `firebase-config.js`. أضف مفتاح reCAPTCHA v3 في `appCheckSiteKey` لتفعيل عمليات الكتابة والتصويت المحمية بـ App Check. فعّل Authentication وFirestore وStorage وCloud Functions وApp Check ثم انشر باستخدام `firebase deploy`.

لا يمكن ترقية الحساب إلى مشرف من الواجهة. أنشئ المشرف من بيئة موثوقة عبر `node provision-user.js <uid> admin`. لوحة الإدارة تسمح بتعديل محتوى الرئيسية ورابط فيسبوك وإضافة التحديات وتعديلها وإدارة المشاريع والمسابقات ومراجعة الأصوات.

تُعرض التحديات المنشورة والمشاريع المعتمدة فقط للعامة من خلال مجموعات بيانات محدودة. ترفض القواعد الكتابة المباشرة إلى المحتوى والأصوات والإعدادات؛ تمر التعديلات عبر Cloud Functions مع صلاحيات وسجل تدقيق. تضغط صور المشاريع إلى أقل من ٩٠٠ كيلوبايت، وتحدد قواعد Storage الحد الأقصى بأقل من ميجابايت.

راجع `firestore.rules` و`storage.rules`. لم يُنشر المشروع ولم تُختبر قواعد Firebase الحية أو محاكيها ضمن هذه النسخة.

## النشر والواجهة الجديدة

- هذه النسخة معدّة لاستضافة الواجهة على Vercel باستخدام Node.js 26.x.
- إعداد Cloud Functions محدد على Node.js 22 داخل firebase.json، لأن Firebase Functions لها إصدارات runtime منفصلة عن Vercel.
- لتحديث الموقع المنشور، ارفعي محتويات هذا المجلد إلى المستودع المتصل بـVercel ثم أعيدي النشر.
- عند إنشاء حساب يدويًا من Firebase Authentication، افتحي `/admin.html`، سجّلي الدخول، ثم استخدمي زر إرسال رابط التحقق. بعد تأكيد البريد أعيدي تحميل الصفحة وسجّلي الدخول.
- عمليات الإدارة المحمية بـApp Check تحتاج إضافة مفتاح reCAPTCHA v3 إلى `appCheckSiteKey` في `firebase-config.js` وإعداد النطاق في Firebase App Check.
